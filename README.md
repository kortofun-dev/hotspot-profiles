# Hotspot Profiles support

Hotspot Profiles is an independent companion for compatible Infinity hotspots.

- [Ask a question or report a problem](https://github.com/kortofun-dev/hotspot-profiles/issues/new)
- [Privacy policy](https://kortofun-dev.github.io/hotspot-profiles/privacy.html)

Include the app version, Android version, and steps to reproduce the problem. Keep passwords, account names, Wi-Fi names, and session identifiers out of public reports.
